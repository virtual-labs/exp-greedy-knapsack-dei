### About the Experiment 

The Fractional Knapsack Simulation Experiment is designed to help students understand the working of the greedy algorithm used to solve the Fractional Knapsack problem. In this experiment, users provide inputs such as knapsack capacity, item weights, and corresponding values, and observe how items are selected based on their value-to-weight ratio. The simulation visually demonstrates the step-by-step selection process, including full and fractional inclusion of items, through interactive execution modes (manual and automatic). It also highlights key concepts such as optimal selection, capacity constraints, and greedy choice property. Overall, the experiment provides an intuitive and practical understanding of how the Fractional Knapsack algorithm maximizes total value efficiently.
